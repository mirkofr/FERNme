Three ways to give an agent memory, fed the identical message stream. FERNme injects a small card built without any model call. Pasting the history injects everything said so far. Mem0 runs one LLM extraction call on every message, and its prompts are counted here from the real Mem0 pipeline.

How this was measured

  • The user and all 300 messages are synthetic and fictional, with a change of taste at message 150. Nothing here describes real users.
  • FERNme numbers are the real card tokens from the engine after each message, with zero LLM calls on the write path. In practice your agent also emits a few tag tokens per reply for FERNme to store.
  • Mem0 numbers come from the real Mem0 open-source pipeline, driven by a deterministic stand-in model so no API was called. Input tokens are counted from the exact prompts Mem0 built; output tokens approximate the reply size. Read tokens are the top 10 memories returned by search.
  • This compares cost only. Recall quality needs the owner-run head-to-head with a real model.
  • Reproduce: python -m fernme.eval.cost_race --turns 300 --with-mem0-prompts
